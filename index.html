Under the hood

How this page is built

One static HTML file with no framework and no build step. Two things load from outside: the fonts and the Three.js library.

HTML + CSS

Semantic HTML holds every word of the dossier, so it reads fine without JavaScript. CSS custom properties, grid and flexbox handle the layout, and glass panels float over the 3D office.

Three.js office

A WebGL scene with an orthographic camera, soft shadows and robots built from simple shapes in code. No 3D model files. On phones the camera turns to look down the office lengthways.

Vanilla JavaScript

An async run engine sequences each mission. Glowing packets fly between robots on requestAnimationFrame, and output-guard counts are read live from the dossier.

Guardrails + router

The input guard uses regular expressions to block prompt-injection phrases and private-data requests. A keyword router picks the agents.

Type

Space Grotesk, Inter and JetBrains Mono from Google Fonts.

Accessibility + hosting

Readable contrast, reduced-motion support, keyboard focus states and a text run trace for every step. Hosted on GitHub Pages.
